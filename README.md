# EDA Projects

This repository contains exploratory data analysis (EDA) notebooks on various real-world datasets.

## 📘 Contents

| Notebook | Description |
|----------|-------------|
| `IndiaGDP.ipynb` | EDA on India's GDP over time |
| `LinearRegression.ipynb` | Linear regression from scratch and comparison with sklearn |
| `ML jobs in US.ipynb` | Analysis of ML job data in the U.S. (roles, salary, demand) |
| `MI on ind gdp.ipynb` | Multivariate analysis on India's GDP |

## 🛠️ Tools Used

- Python 3
- Pandas
- Matplotlib & Seaborn
- Scikit-learn
- NumPy
- Jupyter Notebooks

## 📌 Highlights

- Custom implementation of linear regression
- Use of real-world open data sources
- Visual storytelling through plots and insights

> Note: Datasets are not included due to size. You can download them from:
- [World Bank GDP data](https://data.worldbank.org)
- [ML Job Data on Kaggle](https://www.kaggle.com)
